# 大涨前 1~5 日盘面特征探查（2026-10-10 ~ 2026-11-09）

> 纯研究产物：不接实盘、不改任何线上参数、不进 14 因子。脚本 `backend/scripts/big_move_probe.py`，
> 产物 `D:\Backup\SAS\data\logs\big_move_probe_live.json` / `_ex1104.json`。

## 1. 问题

近一个月单日涨幅 > 8% 的票，在启动前 1~5 个交易日，日线 / 1 分钟 / 5 分钟上有没有共同特征？
如果有，能不能转成可交易信号？

## 2. 口径

- **事件**：日 K `pct_change > 8%`（缓存为前复权，涨跌幅连续），窗口内每个交易日算一次。
  命中 2066 个事件 / 1253 只股票 / 21 个交易日；11-04 单日 326 个（16%）。
- **回看**：T-1 ~ T-5，只用事件日之前的数据，不碰 T 日及之后。
- **对照（关键）**：
  - 日线：**同日 + 同成交额十分位**。不做这层控制，「换手高 / 振幅大」很可能只是小盘股代理。
  - 分钟：同日随机 300 只（1 分钟库一只约 5MB，全市场不现实），结论标注为抽样。
  - 指标：事件值在「它自己的 T-k 日 + 同档」对照分布中的分位，再对事件取平均。
    按日配对，天然消掉「事件集中在 11-04」这类日期效应；0.5 = 无区分度。
- **踩过的坑**：第一版把对照按 code 合并，同一只票只留最后一个日期的值，等于拿 11-06 一个
  截面（全市场低开 2.7%）去比跨 21 天的事件，得出「跳空分位 0.79 / 前 5 日涨天数分位 0.14」
  的假信号。改成按日配对后分别回到 0.49 / 0.52。

## 3. 结论（先看这个）

1. **分钟线没有「大涨前兆」**。早盘/尾盘量占比、VWAP 偏离、尾盘拉升、5m 连阳、最大分钟额
   占比等 20+ 个特征，分位全部落在 **0.46~0.56**；剔除 11-04 后同样。分钟层面基本是噪声。
2. **日线只有「股性活跃度」有中等区分度**：振幅 0.648、换手率 0.647、1m 波动率 0.572。
   但这些在 **T-5 就有 0.63**，T-1 只比 T-5 高 0.03~0.05 —— 是**静态股性**（这些票本来就
   波动大、换手高），不是「临近大涨才出现的变化」，谈不上前兆。
3. **不能转成正期望**。T-1 收盘按振幅取同档 top10%：T 日大涨命中率 5.00%（基线 2.06%，
   2.42x），但 **T-1 收盘买入到 T 日收盘平均 -0.41%**，**T 日开盘买入到收盘 +0.15%**，
   扣掉成本基本为零或负。命中率提升被「更多小跌」抵消。
4. **「超跌反弹」和「追涨」都不显著**：前 5 日累计 0.504、离 MA20 0.514、前 5 日涨天数 0.517、
   T-1 当日涨幅 0.506，全部贴近随机。近一个月大涨更多由市场/题材驱动，个股前兆弱。

## 6. 稳健性

- **剔除 11-04**（326 个事件，16%）后：事件 1740 / 1077 只，振幅 0.650、换手 0.656、
  1m 波动率 0.563；查准率 4.60%（基线 1.85%，2.49x）、T 日均 -0.53%、开盘买 +0.05%。
  结论不变，不是单日普涨驱动。
- 分层：创业板 762 / 主板 1304；涨幅 8~10% 1094、10~15% 809、>15% 163，分层未反转主结论。

## 7. 值得挖 / 不值得挖

**值得**：
- 把「高振幅 + 高换手 + 同成交额档」当**观察池**，不是买入信号；再叠加 **T 日开盘后 30 分钟**
  的确认（属于当日信息，需另做实验，不在本次口径内）。
- 大涨股 T-1 尾盘量占比反而略低（0.464）、VWAP 下方时间略多，与「尾盘抢筹」的直觉相反；
  可作为「不要在 T-1 尾盘追」的弱证据，但强度不足以单独使用。

**不值得**：
- 继续在 1m/5m 上找「大涨前兆」形态（20+ 特征全部接近随机）。
- 把振幅/换手直接加进 14 因子（与现有波动/换手类因子高度共线，且无正期望）。
- 用「超跌」或「前 5 日强势」单因子选股（分位 0.50~0.52）。

## 8. 边界

- 样本只有 21 个交易日、2066 个事件，11-04 单日占 16%；已做剔除检验。
- 未做行业中性化，只做了「同日 + 同成交额十分位」。
- 事件含一字板/涨停开盘，实际买不进；`avg_open_ret` 未剔除这些样本。
- 1 分钟库到 2026-11-06，只用于回看 T-1 之前，不影响结论。
