# 学界 / 业界共识 与 SAS 项目实测对照

> 目的：把"别人已经定论的部分"和"我们自己在 SAS 项目里验到的部分"对齐，避免重复造轮子，也明确哪些结论需要 live 数据再确认。
> 数据来源：Gu-Kelly-Xiu (2020, RFS)、微软 Qlib 官方基准（Alpha158 + A 股 / CSI300 / CSI500）、申万宏源金工 (2026)、国金证券金融工程、国内 A 股 ML 选股对比研究（2020–2024, 5648 只）。

## 1. 学界 / 业界的成熟共识（已定论）

| # | 共识 | 关键证据 |
|---|------|----------|
| C1 | **GBDT/LightGBM 在 A 股截面预测上稳定优于线性多因子** | Gu-Kelly-Xiu (2020)：树模型/NN 把样本外 R² 较 OLS 翻倍；Qlib：Linear Rank IC 0.0475 vs LightGBM 0.0485、年化 7.95% vs 11.43%；A 股对比研究：非线性 Rank IC 0.02–0.03 > LASSO/Ridge |
| C2 | **边际优势中等且统计不硬** | A 股对比研究原话："t 统计量未达传统显著水平，信号经济上有方向性，但统计稳健性仍有限" |
| C3 | **最佳实践是"增强 / 集成"而非"纯替代"** | Qlib DoubleEnsemble（ICDM 2020）年化 11.58%、IR 1.34 居首；申万宏源以 GBM 主分数 + 正交残差并入，CSI500 费后年化超额 9.40%（纯 GBM 8.05%） |
| C4 | **表格数据上树模型 > 深度学习** | Qlib：MLP/LSTM/Transformer 在 Alpha158 上整体不及 LightGBM；今日头条实测 Transformer 年化仅 2.73% |
| C5 | **严格时序交叉验证 + 行业/风格中性化是防过拟合刚需** | Purged/Group CV、Point-in-time、Barra 风险归因已成标准配置 |

## 2. SAS 项目实测（#74 / #76，冻结种子 20261028，18 段 × 21 交易日 × Top300）

| 方案 | 配对中位超额 | 赢段占比 | 判定 | 备注 |
|------|------------|----------|------|------|
| 14 因子 default（控制组） | — | 66.7% 超额>0 | 基线 | 中位超额 +1.11% |
| 线性 Ridge 层 (#74) | **−0.33pp** | 44% | ❌ 未过 3.5pp | 但下行收紧（25 分位 −1.09% vs −4.63%），"风险阻尼器" |
| 纯 LightGBM 层 ml_lgb (#76) | **+4.55%** | 61.1% | ✅ 过线 | 点估计清过线，统计置信度中等 |
| 行业中性层 ml_lgb_ind (#76) | **+3.95%** | 66.7% | ✅ 过线 | 仅板块中性兜底（无真实行业映射） |
| 朴素 0.5 融合 ml_lgb_blend (#76) | **+2.95%** | 61.1% | ❌ 未过线 | 融合反而稀释 ML 优势 |

**统计置信度**：ml_lgb bootstrap 中位 95% CI ≈ [−0.2%, +9.8%]（下界贴 0），符号检验单侧 p=0.24。

## 3. 共识 vs 实测 对齐结论

| 共识 | SAS 实测是否支持 | 说明 |
|------|----------------|------|
| C1（GBDT > 线性） | ✅ 支持 | +4.55%（LightGBM）vs −0.33pp（Ridge），方向完全一致 |
| C2（优势中等且不硬） | ✅ 支持 | p=0.24、CI 下界贴 0，与"统计不硬"吻合 |
| C3（增强 > 纯替代 / 融合需精细） | ✅ 支持 | 朴素 0.5 融合失败，提示应走 DoubleEnsemble / 正交残差路线而非简单平均 |
| C4（树 > 深度学习） | ✅ 未违反 | 本项目未引入深度学习，与共识不冲突 |
| C5（验证纪律刚需） | ✅ 已践行 | Purged Group CV + OOS rank-IC 回退（OOS IC≤0 整段回退 14 因子，2/18 段触发，配对差=0 安全） |

**结论**：方向性结论（"ML 有用、用 GBDT、要中性化、别信裸 DL"）学界早定，我们无需重新发现；但"我们这套具体实现（65 特征 + 行业中性 + 冻结种子验收）在自家数据上是否复现该方向"必须自行验证——这一步任何现成论文都替代不了。验证结果（ml_lgb +4.55% 过线、但置信度中等）与共识同构，因此采用"采纳为候选 + 监控"策略最稳妥。

## 4. 尚待补强的点（非阻塞）

1. **真实行业中性**：拉取 `industry_map.csv` 后重测 `ml_lgb_ind`，检验真行业中性是否优于板块中性兜底。
2. **精细集成**：以 DoubleEnsemble / 正交残差相加替代朴素 0.5 融合，释放 ML 与多因子的协同增益（呼应 C3）。
3. **Live 前向验证**：影子账户 `default` vs `default_ml` 跑满约 1 个月（首个判读 ≈ 2026-12-01），确认 live 数据复现回测正超额。
