# 每日收盘复盘（按日分节）

> **口径说明**：本节里的「今日涨跌」是**单只票当日**涨跌幅、「浮盈亏(vs成本)」是截至今日的
> **未实现**浮盈——两者都不是「这只票从买入到清仓到底赚了多少」。要看每只票全生命周期的
> **真实盈亏**（已实现 + 当前浮盈，FIFO 批次口径）以及账户每日盈亏曲线，见
> [`position_pnl.md`](./position_pnl.md)（由 `scripts/position_pnl.py` 每日复盘时自动刷新）。
> 想看「该调哪个参数」的**诊断信号**（滚动窗口指标 + 候选参数，不自动改值），见
> [`param_advisor.md`](./param_advisor.md)（由 `scripts/param_advisor.py` 每日复盘时自动刷新）。
